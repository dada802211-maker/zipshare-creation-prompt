# zipshare-creation-prompt

日本語のZIP共有アプリ「zipshare」を、空のディレクトリから開発AIに作成してもらうためのプロンプトです。既存の完成コードをもとに、機能・画面構成・API・保存方式・開発環境・デプロイ・検証条件をまとめています。

このリポジトリにはプロンプトと説明文書を収録しています。実行可能なアプリケーションコードは、プロンプトを使って別の作業フォルダに生成します。

## ファイル構成

```text
README.md                     このリポジトリの説明と使い方
zipshare-creation-prompt.md    開発AIに渡す実装指示
```

## 使い方

1. [zipshare-creation-prompt.md](./zipshare-creation-prompt.md) を開きます。
2. 生成先となる空の作業フォルダを用意します。
3. プロンプト内の「想定開発先」を、そのフォルダのパスに変更してAIへ渡します。既定の記載は `C:\laragon\www\multiple-uploads` です。既存の完成コードがある場合は、別の空フォルダを指定してください。
4. 文書冒頭の区切り線（`---`）より下をコピーし、ファイルの作成・編集とコマンド実行に対応した開発AIに貼り付けます。
5. AIに実装と検証を完了させ、生成されたREADME、実行結果、画面を確認します。

プロンプトをファイルとして参照できるAIには、次のように指示することもできます。生成先のパスは自分の環境に合わせて変更してください。

```text
zipshare-creation-prompt.md を読み、区切り線より下の要件に従って
ZIP共有アプリを実装してください。
生成先は C:\laragon\www\zipshare-new とし、空のフォルダから作成してください。
実装、起動スクリプト、デプロイ用ビルド、README、結合テストまで完成させ、
実行した検証結果を報告してください。
```

## 生成するアプリの主な機能

- ユーザー登録・ログイン・ログアウトと、PHPセッションによる認証。
- 1〜20ファイル、合計100MiB以下のファイルを1つのZIPにまとめて登録。
- 既存ZIPを1個アップロードして登録。
- タイトル、説明、ダウンロード名、公開範囲の設定。
- タイトル・説明・登録者の検索と、一般公開・自分の登録による絞り込み。
- 投稿者による登録情報の編集・削除。
- 日本語ファイル名のダウンロードと、ZIP内の同名ファイルの連番処理。
- グリーン系のレスポンシブUI、認証ダイアログ、操作結果のトースト通知。
- 開発サーバーの一括起動、Apache向けリリース生成、HTTP結合テスト。

### ダウンロード権限

| 公開範囲 | ダウンロードできる人 |
| --- | --- |
| 誰でも | 未ログインを含む全員 |
| 登録ユーザーのみ | ログイン済みの全ユーザー |
| 選択したユーザーのみ | 投稿者本人と、選択されたユーザー |

投稿のタイトル・説明・登録者などは未ログインでも一覧に表示します。公開範囲で制限するのはZIPのダウンロードです。

### 編集・削除の仕様

投稿者が編集できるのは登録情報です。ZIP本体の差し替えと投稿者の変更はできません。「登録情報を削除」はDBの投稿情報を削除し、ZIP本体をサーバーに残します。削除後は一覧とダウンロードAPIからアクセスできなくなり、画面からの復元機能はありません。

## 生成後の起動・検証

以下は、アプリ生成後に**生成先のプロジェクト直下**で実行する想定のコマンドです。このプロンプト保管リポジトリでは実行できません。実際の手順は生成されたアプリのREADMEも確認してください。

### 初回セットアップと起動

```powershell
npm --prefix front ci
npm --prefix front run build
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

ブラウザーで [http://127.0.0.1:8011](http://127.0.0.1:8011) を開きます。初期ユーザーは作成しない仕様のため、画面からユーザー登録します。

開発時は、起動済みのPHPサーバーを停止してから以下を実行し、PHPとViteを同時に起動します。

```powershell
npm --prefix front run dev
```

### 検証

```powershell
npm --prefix front run build
npm --prefix front run lint
python tests/smoke.py
Get-ChildItem php/*.php,public/*.php | ForEach-Object { php -l $_.FullName }
```

結合テストは一時ディレクトリ・一時DB・空きポートを使用し、認証、CSRF、ZIP生成、権限、編集・削除、ZIP保持、内部ファイルの非公開を検証する仕様です。

### 配布用ビルド

```powershell
npm run build:deploy
```

`release/YYYY-MM-DD/HH-mm-ss-SSS/` にビルド済みフロント、PHP、`public_html/`、保存先保護設定、配置手順を出力する仕様です。開発用DB・ZIP・セッションは含めず、更新時はサーバーの既存 `storage/` を保持します。

## 利用上の補足

- このプロンプトは同等の機能と画面構成の再現を目的としており、元コードの文字単位の一致や画面の完全一致を保証しません。
- 生成結果は使用するAIや実行環境によって変わるため、ビルド・テスト結果と実画面を確認してください。
- メール確認、パスワード再発行、ウイルススキャン、アカウント単位の容量制限、ログイン回数制限は実装対象外です。
- 外部公開時はHTTPSを設定し、削除後も残るZIPを含めて保管容量を管理してください。
